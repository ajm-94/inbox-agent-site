inbox-agent privacy policy

Last updated: 7 October 2026

inbox-agent is a personal tool used only by its owner, on mailboxes and accounts the owner controls. It has no other users.

What it accesses

With the owner's authorisation, it reads messages in the owner's Gmail accounts (read-only access) to classify them as important, normal or junk and to produce summaries for the owner.

How data is used and stored

  • Message data is stored on the owner's own machine (and, if deployed, the owner's own cloud project) and is used only to triage and summarise messages for the owner.
  • Message content is sent to Anthropic's API for classification and summarisation, under Anthropic's API terms.
  • Data is not sold, shared with third parties for advertising, or used to train models.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
